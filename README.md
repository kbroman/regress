## Installation
Install the package from [CRAN](https://cran.r-project.org/package=regress):

```r
install.packages("regress")
```

Alternatively,  install it from [R
universe](https://kbroman.r-universe.dev):

```r
install.packages("regress", repos=c("https://kbroman.r-universe.dev",
                                    "https://cloud.r-project.org"))
```

Or use [remotes](https://remotes.r-lib.org) to install it from its GitHub source:

```r
install.packages("remotes")
remotes::install_github("kbroman/regress")
```
